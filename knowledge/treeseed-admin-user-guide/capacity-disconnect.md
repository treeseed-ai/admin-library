Disconnect revokes this team's provider connection. New work is no longer authorized through it, and running work may be interrupted. It does not uninstall software from the machine.

Type DISCONNECT to confirm the selected provider. Check ongoing work first. Reconnection requires a new authorized enrollment; rotating the team registration code is not a substitute for revocation.
