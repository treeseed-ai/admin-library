Open Registration and reveal the team's current registration code only when needed. Download the installation configuration and supply it to the supported Debian installation process on your machine. This file is enrollment material; keep it out of source control and public logs.

The code identifies the team and permits a pending request, not execution. Review the machine's identity before approving. Rotating the code immediately invalidates the old code for new registrations; it does not revoke already approved providers or their independent credentials. Use Disconnect to revoke an existing connection.
