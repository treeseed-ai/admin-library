A provider is a machine that registers with your team. Installation and registration happen on the machine; this page does not SSH into it or create it.

Use search and status filters to find a provider. Open it for Overview, Permissions, Activity and, if authorized, Disconnect. Approved means the team accepted its identity, not that the machine is online. Offline means its latest availability has expired. Unknown means no trustworthy report is available; do not interpret it as healthy.
