Environment profiles describe variables the provider offers; the actual values stay on the provider. Assignment access lists the selected provider's grants, variable names, network destinations and expiry.

No profiles means none have been reported. A loading error is not an empty grant list. Expired grants do not authorize new access. New grant creation is not enabled in this editor until authoritative assignment policy proofs are available; never invent proof digests or assume approval grants secret access.
