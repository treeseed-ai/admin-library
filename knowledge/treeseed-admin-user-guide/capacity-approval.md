A new provider remains pending until an authorized team administrator approves or rejects it. Check the machine identity and offered capabilities before approving. Reject unexpected requests.

Approval is not blanket permission to use host secrets, network destinations or every project. Execution still requires current availability and the applicable assignment, provider and sandbox authorization.
