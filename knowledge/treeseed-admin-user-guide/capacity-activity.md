Activity shows reported availability sessions, not a live stream of running tasks. Last contact is the latest report timestamp, displayed in your chosen time zone.

An approved provider with expired availability is offline. Check the machine's managed Agent service and control-plane connectivity before expecting it to accept work. A successful installation receipt alone is not proof of current health.
